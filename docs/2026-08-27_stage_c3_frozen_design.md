# Stage C3 凍結設計（執行前定案）

日期：2026-08-27
狀態：已凍結，尚未執行
前置：C2 完成（`5c01db2`），2016 資料稽核完成，逐日稽核執行中

這份文件在看到 2016 逐日稽核結果**之前**寫定。C2 的結論脆弱，
若等結果出來再訂判準，就是用結果挑規則。

## 為什麼原定的 C3 不能照跑

C2 的凍結規則是 5/5 進 10-seed confirmation，top-500 對三個 control 都達成。
但這裡真正的脆弱性不在 seed 之間，而在 fold 之間：

```text
real − topology_shuffle（top-500）
        全 13 折   5/5 seeds   +0.00469
        排除 2016  3/5 seeds   +0.00072   ← 2016 一年貢獻 85%
```

增加 seeds 只降低 seed 變異。照原案跑，只會得到一個更精確的、
對 2016 依賴的估計。

## 凍結的判準

| 項目 | 值 |
|---|---|
| Seeds | 41–50 |
| Universe | top-500（C2 中唯一通過探索門檻的規模） |
| Graph | G_corr，其餘設定與 C2 完全相同 |
| 主要 control | `topology_shuffle` |
| 次要 control | `relation_shuffle` |
| seed-level 門檻 | 至少 9/10 |
| fold-level 門檻 | 至少 9/13 折的跨 seed 平均效果為正 |
| 穩健性 | leave-one-fold-out：逐一排除每折重算，13 次結論都不得翻轉 |
| 報告 | 效果量與 bootstrap 信賴區間，不只 p-value |

### 三項同時成立才算通過

1. seed-level ≥ 9/10
2. fold-level ≥ 9/13
3. leave-one-fold-out 13 次全部維持結論

任一項不成立即為未通過。**移除任一折就使結論翻轉者，不得稱為穩健通過。**

### 不得做的事

- 不得改用 `self` 或 `no_graph` 作為主要證據。`self` 只是價格模型基準，
  贏它不構成語義證據。
- 不得因結果不理想而把主要 control 換成 `relation_shuffle`。
- 不得排除 2016 之後宣稱通過，也不得只憑 2016 宣稱通過。
  兩種都是用結果挑樣本。
- 不得擴充 seeds 到 10 以上以求跨過門檻。

## C3 通過也救不回 H1

這點必須寫在 C3 的結論裡，避免日後被改寫：

> H1 要求效果隨 universe 規模增強。C2 量到的最小效果是
> top-30 −0.01152、top-100 −0.02176、top-500 +0.00322，不是單調的。
> **H1 依凍結規則已判定不成立，C3 不會改變這個結論。**

C3 能回答的只有一個問題：top-500 的 G_corr 相對 `topology_shuffle` 的
微弱優勢是否跨時期穩健。即使全部通過，可宣稱的最強說法是：

> 在 top-500 上，動態相關圖相對於度數匹配的隨機圖有微弱但穩健的
> 橫斷面排序優勢；效果量約 0.005 Rank IC，且模型幾乎不擊敗常數預測器。
> 這不構成交易價值主張，也與語義 KG 無關。

## 決策流程

| C3 結果 | 行動 |
|---|---|
| 三項判準全過 | 稱為「top-500 的弱而有限訊號」，做小規模 portfolio 驗證，仍不接 RL |
| leave-one-fold-out 不穩定 | 停止把 G_corr 接入 RL，轉 H3 風險／共動目標 |
| 仍勝不過 `topology_shuffle` | 正式結論：目前資料與圖消費方法沒有穩定報酬訊號 |

三種結果都不進 RL。依 `RESEARCH_PROTOCOL.md` §7，
supervised gate 與簡單經濟 backtest 都通過才另立 slow-policy RL spec。

## 一併記錄的設計缺陷

C2 的 2016 稽核暴露了 mask 定義的一個問題：它要求未來 20 日 target 完整，
等於**以存活 20 天為條件篩選橫斷面**。這個 forward-looking selection
在所有年份都存在，在高下市年份特別強：

| | 2016 | 其他年份 |
|---|---:|---:|
| 期間內停止交易的成員 | 26 | 9.8 ± 3.8 |
| 因 target 不完整被排除（每日） | 2.06 | 0.83 ± 0.42 |

mask 對所有 variant 一致，因此不直接偏袒 real，但它改變橫斷面的組成。
更正確的做法是保留中途下市的股票、以 delisting return 補完部分視窗，
而不是整檔排除。

**C3 沿用現有 mask**，以維持與 C2 可比。此缺陷列為 Stage B 的已知限制，
若之後要重建資料層再處理。
