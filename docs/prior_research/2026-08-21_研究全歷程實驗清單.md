# KG + RL 研究全歷程實驗清單

日期：2026-08-21  
專案：`GraphRagTrading/0601_atten_V2`  
用途：教授簡報與研究交接

## 一、研究主張與判定框架

核心問題：

> 在時間正確、語義正確的前提下，金融 KG 是否能為圖模型與下游投資組合任務提供相對於 no-graph、self、relation-shuffle、topology-shuffle 的增量價值？

證據分成四層：

1. KG 事實、來源與時間品質。
2. 模型是否真的使用圖與關係語義。
3. 圖訊號是否能預測 out-of-sample 市場目標。
4. 訊號是否能轉成 return、Sharpe、MDD 等交易績效。

研究標準：5 seeds 時以 5/5 作為 exploratory 進階門檻；10 seeds 時以至少 9/10 為強證據。只贏 self、不贏 shuffle，不算 semantic KG 證明。

## 二、實驗時間線

### 1. 原始 Attention/GPM + RL baseline

- 建立 Dow 30 universe、固定 5 檔 portfolio、30 日 OHLCV window。
- KG embeddings 作為 query/key，價格窗口作為 value；attention encoder 先做 supervised return pretraining，再凍結、訓練 allocation head/RL。
- 目的：驗證基本 pipeline 可收斂，並建立 return、Sharpe、MDD、turnover 指標。
- 結果：RL 可以訓練，但真實 KG 相對 controls 沒有穩健增益；後續所有實驗改用 paired controls 與分層 Gate。
- 參考：`docs/RL_Attention收斂與Walk-Forward驗證紀錄.md`、`docs/2026-08-06_GPM_KG時間尺度與慢速交易驗證紀錄.md`。

### 2. Gate 0：RL consumer pipeline 正控制

- 給 policy 明知含 future information 的「明天真報酬 z-score」oracle。
- 對照：random oracle、equal-weight；seeds 41–45。
- 真 oracle：Sharpe 約 1.246、total return 約 0.449；5/5 贏 random/equal-weight。
- 結論：environment、PVM、action blend、gradient pipeline 能使用真正逐日訊號。
- 沒有證明：真實 KG 有效。
- 參考：`docs/2026-07-29_研究進度總結_給外部審查.md`。

### 3. Gate 1 v1：合成動態圖，R-GCN

- DGP：`r[t+1] = β·A_t·x_t + γ·f_t + ε`，typed/directed graph 含已知可交易訊號。
- R-GCN + residual gate；10 seeds × 4 transitions。
- 結果：simultaneous win 28/40 = 70%，未達 90%；Spearman 0.082。
- 結論：架構有部分利用圖，但設定尚不穩定。

### 4. Gate 1 v2：加入 GRU

- 目的：檢查是否需要跨日記憶。
- 結果：simultaneous win 約 7.5%，Spearman 0.007，全面惡化。
- 根因：GRU 輸出取代原 state 而非 residual；160 步 BPTT 且 hidden 未 detach。
- 結論：不能把失敗解讀成「需要 GRU」；先修正 state integration。

### 5. Gate 1 action-blend diagnosis 與 v1.1 PASS

- layer-wise 結果：raw logits/softmax 對真實 alpha 的 Spearman 0.57–0.85，但 `action_blend=0.025` 後降至約 0.05–0.4。
- 掃描 `action_blend ∈ {0.025, 0.10, 0.25, 1.0}`：Spearman、top-1、Sharpe、mask 後績效下降均單調改善。
- 固定 `action_blend=1.0` 後，用全新 10 seeds、5 conditions：40/40 = 100% simultaneous wins；Spearman 0.902、top1 hit 0.717。
- 結論：R-GCN/RL 架構在「訊號強且即時」時確實能學會圖；真實 KG 仍需另外驗證。

### 6. 真實 KG 品質工程與 provenance

- 補上 triple → relationship → text unit → document → report provenance。
- 修正 `normalize_entity_key` 的 `WALMART+` collision。
- 修正 `employs_person` domain/range 漏洞，隔離 26 條錯誤關係。
- 補 SEC `filed_date`/accession metadata，修正 NULL filing date 可能通過 cutoff 的 leakage。
- 建立 snapshot、relation validation、evidence audit 與 write-once KG archive/package。
- 目前最新完整 archive：snapshot 29，包含 raw GraphRAG output、triples、rejected triples、PyKEEN runs 與 manifest。

### 7. Gate 2A：真實 10-K/逐字稿關係可行度

- 30 檔 Dow universe 的直接 company-company edges 極少：10-K snapshot 18 只剩 2 組人工確認 pair；transcript snapshot 16 另有 2 組，兩者不重疊。
- ontology accept 約 62.4%，但 direct pair coverage fail；report → filed_date/accession 初期為 0%。
- 結論：不能直接把當時的 KG 接進報酬傳導交易；但尚不能判定原文沒有關係，需做 recall audit。

### 8. Gate 2B：known-pair recall audit 與抽取修正

- 以 102 組 DEF14A peer probe set，修正 passage-specific mention、resolver 單調性與 ticker alias。
- 修正前 relationship extraction 約 1.96%；修正後 snapshot 22 約 6.86%，ontology accepted/ticker mapped 約 2.94%。
- 找到系統性 failure：列舉式 competitor/partner list 被漏抽、delimiter drift 使 parser 靜默丟 record、alias fragmentation 使 ticker 對不上。
- 加入 Example 5、delimiter parser patch、resolver alias patch。
- held-out extraction benchmark：prompt-dev recall 42.4%、held-out recall 39.1%，但 precision 約 15.3%，且 LLM temperature=1.0 導致單次抽樣不穩。
- 多 seed prompt v2/v3：Example 5 對 recall 有可重現改善，但仍非高 recall，也不能直接推論交易價值。

### 9. 靜態 KG 結構與經濟關聯診斷

- sector test、link prediction、embedding similarity、Mantel/return-correlation、人工 known-pair recall：支持 KG 不是完全隨機，且 relation/topology 有可學習結構。
- residual-correlation analysis：部分人工確認的 direct competition edges 與同期 residual co-movement 有關。
- exploratory holdout：17 組修正後只有 4 組超過正確產業/跨產業對照；後續 frozen test 6 組只 3/6 通過預設門檻，FAIL。
- 結論：可支持「KG 有結構/候選關聯」，不能支持「關係可預測未來報酬」。

### 10. 原始 static KG → GPM RL

- variants：real、self、permuted；5 seeds；比較 total return、Sharpe、MDD。
- 無 relation gate：real return 0.3132、Sharpe 1.3993；self 0.3192、1.4048；permuted 0.3194、1.4094。
- relation gate：real return 0.3149、Sharpe 1.4106、MDD -0.2026；permuted Sharpe 1.4129。
- 結論：真實 KG 沒有穩健 return/Sharpe 增益；只出現輕微 MDD 方向，不能宣稱交易改善。

### 11. Horizon sweep：找時間尺度

- supervised target/evaluation 改為 horizon `{1, 5, 20, 60}`。
- h1/h5/h20：real 沒有穩定優勢，部分 MSE/IC 反而較差。
- h60 5 seeds：real IC 0.0769 高於 self 0.0487、permuted 0.0452，MSE 約 4/5 勝；因此補跑 10 seeds。
- h60 10 seeds：real vs self MSE 勝 8/10、p=0.0195；但 real vs permuted IC 5/10，permuted IC 反而高；direction 沒改善。
- 結論：最多支持長期數值校準/regularization 候選，不是 semantic KG alpha。

### 12. Slow h60/h120 ranking backtest

- 以 supervised h60/h120 prediction，每 60/120 日 rebalancing、top-2 equal-weight，完全不跑 RL episodes。
- h60 10 seeds real vs relation-permuted：return 0.4017 vs 0.3296、Sharpe 1.6456 vs 1.3535，但只勝 8/10、p=0.0801；volatility 只勝 5/10。
- h120 5 seeds：real Sharpe 1.2351，但 topology-permuted 1.4209；real MDD -0.2679，遠差於 topology -0.1835。
- 結論：有探索性候選，但無法通過 semantic control，不能直接改 RL。

### 13. KG → RL interface experiments

- slow KG context injection：smoke fail，無穩定 reward/Sharpe 增益。
- slow prior-action transfer：smoke fail，無穩定 action transfer。
- h120 auxiliary pretraining → RL：smoke fail。
- RL loss/head pretraining ablation：smoke fail，未改善收斂或交易結果。
- 結論：問題不是單一 reward/loss 小調參可以解決；先停 RL integration。

### 14. Risk/action transfer experiments

- 固定 policy + adjacency risk overlay：2023→2024 real MDD/volatility/turnover 全部 0/5 改善；2024→2025 Sharpe 5/5，但 MDD 2/5、volatility/turnover 0/5，且 turnover 上升。
- train-calibrated covariance-aware overlay：`kg_cov` Sharpe 1.1915、MDD -0.1957，均不如 base Sharpe 1.3444、MDD -0.1808；topology control 也較好。
- 結論：固定 adjacency/covariance overlay stop，不再調 lambda 或接回 RL。

### 15. SEC temporal event KG pivot

- SEC metadata：2019–2025，30 tickers，4,018 filings，210/210 ticker-year，0 errors。
- bounded source text：627/627 files，保留 accession、filing date、SHA-256。
- DEF14A extraction：799 `compensation_peer` event rows、135 unique pairs、每筆 evidence quote 與 `known_as_of=filing_date`。
- month-matched event study：h20/h60/h120 observed absolute pair spread 比 placebo 高 +0.0058/+0.0116/+0.0232，但 signed spread 接近 0。

### 16. Dynamic event dispersion gate 與最後消融

- dynamic graph：point-in-time `known_as_of <= date`、365 日 decay；target 是未來 60 日 pair absolute spread。
- 5 seeds：real MSE vs price-only 勝 4/5；vs time-shuffle 勝 3/5；vs topology-shuffle 勝 4/5；Spearman 無穩定改善。
- count/recency ablation：real MSE 0.013413；count-only 0.013245（反而更好）；real vs time-shuffle 3/5；Spearman real 只勝 count-only 0/5。
- 最終結論：改善可由事件量、recency 或模型容量解釋，尚未證明 semantic/time-aware KG value；停止此 relation 的 RL integration。

## 三、目前能對教授說的結論

### 已經證明

1. RL consumer pipeline 沒壞；oracle 與合成動態圖能穩定學習強、即時、因果對齊訊號。
2. KG 工程與審計能力已大幅改善：provenance、point-in-time、evidence、snapshot archive 都有可重現產物。
3. 真實 KG 具備某些圖結構與同期關聯，但結構存在不等於交易增量價值。
4. static KG、long-horizon KG、dynamic event KG 在目前 controls 下都沒有穩健證明 semantic relation 能改善 downstream trading。

### 尚未證明

- KG 能改善 daily RL reward、return、Sharpe 或 MDD。
- GraphRAG 抽取的 relation 足夠穩定、完整、可直接交易。
- `compensation_peer` 能代表未來方向性報酬；目前更像未證實的慢速 risk/dispersion candidate。

## 四、後續建議

不再跑目前 KG relation 的 RL hyperparameter sweep。若研究仍要延伸，只接受一個全新的、預先凍結的事件類型與 evidence benchmark，先通過 semantic/time-shuffle supervised gate，再考慮 slow-policy；否則把本研究正式寫成「KG 結構品質與下游效用分離的負結果/方法論案例」。
