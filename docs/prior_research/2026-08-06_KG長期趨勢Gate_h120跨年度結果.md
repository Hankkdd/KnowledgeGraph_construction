# KG 長期趨勢 Gate：h120 跨年度結果

日期：2026-08-06

## 設計

- target：未來 120 trading days 的 cross-sectional market-relative cumulative return
- model：daily OHLCV temporal encoder + graph message passing + per-stock trend head
- variants：price-only、real、relation-permuted、topology-permuted、sector-only
- two temporal windows：2023→2024、2024→2025
- each window：5 paired seeds（41–45）、30 epochs；無 RL episodes

## 2023→2024

Artifact：`0601_atten_V2/artifacts/diagnostics/supervised_graph_trend_gate_2023_h120_5seed/`

- real vs price-only Spearman：`5/5`，real `0.0458` vs `-0.0067`
- real vs price-only direction：`5/5`，real `0.5195` vs `0.4937`
- real vs price-only top-20 recall：`5/5`，real `0.2327` vs `0.1996`
- MSE：real `0.0413`，price-only `0.0354`，real 較差

## 2024→2025

- real vs price-only Spearman：`5/5`，real `0.0484` vs `0.0009`
- real vs price-only direction：`5/5`，real `0.5180` vs `0.4974`
- real vs price-only top-20 recall：`4/5`，real `0.2351` vs `0.2047`
- MSE：real `0.0412`，price-only `0.0365`，real 較差

## Cross-window interpretation

把兩個 temporal windows 視為 10 個 paired observations：

- Spearman：real vs price-only `10/10` 同方向；
- direction：`10/10` 同方向；
- top-20 recall：`9/10` 同方向；
- MSE/MAE：real 沒有改善，且通常較差。

real 也在 h120 的 Spearman/direction/top-recall 上大多勝過 relation-permuted、topology-permuted 與 sector-only controls。這表示目前最有力的證據是：**KG graph message 能提供跨年度的長期 cross-sectional ranking/context signal**，而不是精準的 return magnitude calibration。

## Gate decision

**Gate A 通過，但只通過 ranking/direction branch。**

可以進入下一階段：把 KG 做成 slow context，輔助 daily RL；不得把 KG 當作 daily return oracle，也不得使用 MSE 結果宣稱報酬幅度預測改善。

## 下一 Gate B

建立 slow-context action-transfer / small RL test：

1. `price_only`：daily price state；
2. `price + real KG slow context`；
3. `price + relation-permuted`；
4. `price + topology-permuted`；
5. slow context 每 20 或 60 trading days 更新一次，其餘 daily steps 固定；
6. 先跑 frozen-policy action transfer，再跑小型 5-seed RL；primary 為 Sharpe、MDD、volatility，secondary 才是 total return。
