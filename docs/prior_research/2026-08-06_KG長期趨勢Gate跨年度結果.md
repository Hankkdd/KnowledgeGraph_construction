# KG 長期趨勢 Gate：跨年度結果

日期：2026-08-06

## 設計

- target：未來 60 trading days 的 cross-sectional market-relative cumulative return
- universe：30 stocks；每日 OHLCV window → node encoder → graph message passing → per-stock trend head
- variants：price-only、real、relation-permuted、topology-permuted、sector-only
- seeds：41–45；30 epochs；沒有 portfolio RL episodes

## 2023→2024

Artifact：`0601_atten_V2/artifacts/diagnostics/supervised_graph_trend_gate_2023_5seed/`

- real vs price-only Spearman：`5/5`，real mean `0.0321` vs `-0.0042`
- real vs price-only top-20 recall：`5/5`，`0.2310` vs `0.2029`
- real vs price-only direction：`4/5`，`0.5084` vs `0.4966`
- 但 real MSE/MAE 較差：MSE `0.01724` vs `0.01576`；MAE `0.1040` vs `0.0991`
- real 也勝過 relation/topology/sector controls 的部分 ranking metrics

這個年度支持「KG 可能改善長期 cross-sectional ranking」，但不是 magnitude calibration。

## 2024→2025

Artifact：`0601_atten_V2/artifacts/diagnostics/supervised_graph_trend_gate_2024_5seed/`

- real vs price-only Spearman：只有 `2/5`，mean `0.0374` vs `0.0345`
- real vs price-only top-20 recall：只有 `2/5`，`0.2128` vs `0.2184`
- real vs price-only MSE/MAE 較差：MSE `0.01840` vs `0.01738`；MAE `0.1052` vs `0.1018`
- real 對 relation-permuted 的 Spearman/direction 有改善，但對 topology/sector 並不全面勝出

這個年度沒有 replication 出 2023→2024 的 real-vs-price-only trend effect。

## 跨年度判斷

把兩個 temporal windows 的 5 seeds 視為 10 個 paired observations 時：

- real vs price-only 的 Spearman 與 top-20 recall 都只有約 `7/10` 同方向，未達 `9/10`。
- real vs relation-permuted 的部分指標可達 `9/10`，但 top-20 recall 不一致；這不能證明 relation semantics，可能是 graph capacity 或 regularization。
- magnitude MSE/MAE 沒有穩定改善，甚至常常變差。

## Decision

**長期趨勢假設目前為 exploratory，尚未通過 replication gate。** KG 可能在特定年度提供 ranking/context benefit，但現有 static graph 不能被宣稱為穩定的 long-term trend signal。

因此暫不接入 daily RL。下一步若繼續，應先做：

1. graph capacity-matched price-only baseline；
2. relation-type 與 graph-age ablation；
3. 更長 horizon（例如 h120）但只做事前指定的一個 sensitivity；
4. 檢查 2024→2025 graph snapshot 的 coverage/semantic drift。
